Privacy policy

Personal archive, a private single-user tool. Last updated: October 2026.

In short

The tool is used only by its owner, with the owner's own Google account. Nobody else receives any data from it: there is no service, no other account, no analytics and no telemetry.

Google user data

The tool asks Google for one permission:

  • drive.file: to create, read, update and delete only the files and folders the tool itself makes in the owner's Google Drive. It cannot see or change any other file in that Drive.

How it is used: only to store, check and retrieve the owner's own files, and to remove the tool's own old files on the owner's schedule. It never touches files it did not create.

Where it is kept: the sign-in stays on the owner's own equipment. The files are stored encrypted, readable only with the owner's key.

Sharing: Google user data is not shared with, sold or transferred to anyone. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It is not used for advertising, and no person other than the owner reads it.

Your choices

  • Remove the tool's access at any time in the Google account: myaccount.google.com/permissions.
  • Files the tool made in Drive stay in that Drive and can be deleted there at any time.
